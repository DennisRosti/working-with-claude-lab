# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

- **App:** Spring Boot 3.2 / Java 17 REST API (plain SQL via Spring JDBC, Flyway, no JPA) plus vanilla JS in `src/main/resources/static/` (no build step, inline SVG charts). Tickets live in `docs/tickets/`; the ticket wins over chat.
- **Run:** `docker compose up -d db && ./mvnw spring-boot:run`, or `SPRING_PROFILES_ACTIVE=demo ./mvnw spring-boot:run` without Docker (H2 in memory). **Test:** `./mvnw test` (25 tests, single test: `-Dtest=Class#method`) and `npm test` (45 tests, single test: `npx jest <file>` or `-t "<name>"`). Neither needs a database.
- **Done means:** both suites green with counts reported, every new `id` in `index.html` added to `REGISTERED_IDS` in `src/test/javascript/setup/loadApp.js`, app restarted.
- **Constraints:** SQL must run on PostgreSQL 16 and on H2 in PostgreSQL mode.
- **"Today" = 2026-09-21** (`ops.today` → `Clock` bean in `ClockConfig`). Always use the injected `Clock`. The frontend reads the date from `/api/health`. Test expectations are exact seed figures. `V2__seed.sql` is generated by `tools/make_seed.py`.
- **Structure:** controller → `DateRange.resolve` → repository (SQL) → record. `app.js` exports `initApp(document, fetchImpl)` for both browser and Jest. `loadApp.js` fakes every `/api` endpoint, so new endpoints need a case there.
- pom.xml dependencies are frozen. Any change needs a CHG ticket.
